# GO IV

[GO IV](https://frank-apps.github.io/goiv-website/)（GO IV Calculator）是為 Pokémon GO 玩家設計的 IV 計算 App 官方說明站，內含介紹（含操作手冊與模擬器截圖 `manual/`）、隱私權與支援頁面。

## 這個 App 做什麼

- 上傳遊戲內**精靈摘要截圖**，App 會辨識 CP、HP 與星塵需求，並依圖鑑數值**反推可能的 IV 組合**與等級。
- 提供圖鑑瀏覽、IV 計算歷史與收藏；圖鑑、歷史與收藏皆保存在**本機**，由您自行掌控資料。
- 參考好友、進化與**三聯盟 PvP**（超級／高級／大師）相關資訊。

隱私權與支援請見下方連結。
